# Commits and Attribution

- Use Conventional Commits: `type(optional-scope): imperative description`.
- Allowed types: `feat`, `fix`, `docs`, `style`, `refactor`, `perf`, `test`, `build`, `ci`, `chore`, `revert`. Add `!` before the colon for a breaking change.
- Write every commit message as exactly one line, with no body and no footer.
- Keep commits small and focused. Preserve unrelated user changes.
- Commit at the end of work.
- Do not co-sign commits. No `Co-Authored-By:` trailer, no `Claude-Session:` trailer, and no "Generated with Claude Code" line, in commit messages or PR bodies.
