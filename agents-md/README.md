# AGENTS.md Chunks

Reusable sections for `AGENTS.md` / `CLAUDE.md` files. One topic per file so they can be mixed and pasted into a project as needed.

Naming: `topic.md` (e.g. `git-conventions.md`, `sveltekit-stack.md`, `writing-style.md`).

Keep each chunk self-contained, starting with its own `#` heading.
