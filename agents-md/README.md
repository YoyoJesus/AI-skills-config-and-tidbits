# AGENTS.md Chunks

Reusable sections for `AGENTS.md` / `CLAUDE.md` files. One topic per file so they can be mixed and pasted into a project as needed. Each chunk is self-contained and starts with its own `#` heading.

| Chunk | Covers |
| --- | --- |
| [commits-and-attribution.md](commits-and-attribution.md) | Conventional commits, one-line messages, no co-signing |
| [writing-style.md](writing-style.md) | No em dashes or overclaiming, plus an ASCII-only variant |
| [code-style.md](code-style.md) | Comments, icons, typing, scope of changes |
| [sveltekit-stack.md](sveltekit-stack.md) | Default stack, npm commands, SvelteKit layout rules |
| [pr-workflow.md](pr-workflow.md) | Branch-only PRs, pre-push checks, CRLF lint note, PR body template |
| [privacy-and-untrusted-input.md](privacy-and-untrusted-input.md) | Uploads, secrets, synthetic data, AI API calls |
| [testing.md](testing.md) | Proportional testing or a no-tests variant |
| [handoff-summary.md](handoff-summary.md) | End-of-work summary format |
| [ai-disclosure.md](ai-disclosure.md) | Provider/model/harness PR footer or AI-assistance disclosure policy |

Rule sets from other authors are linked with credit in [third-party.md](third-party.md).

Sourced from my global `CLAUDE.md` and the AGENTS.md files in ResumeSmith, CardSmith, Dependency-Domino, holotrace, industry, and TCCYOA.
