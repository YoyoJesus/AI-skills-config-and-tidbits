# Writing Style

Applies to docs, UI copy, comments, commit messages, and PR text.

- No em dashes.
- No overclaiming language. Do not say something is tested, secure, fast, or complete unless it has been shown to be.
- Professional but not stuffy.
- Never invent facts, dates, names, numbers, or links to fill space.
- Say each fact once per page.

## Strict variant

Use ASCII characters only. No em dashes, curly quotes, ellipsis characters, arrows, middle dots, or emoji, anywhere in the repo: code, comments, UI copy, docs, and commit messages.
