# Plugins

Plugins bundle skills, commands, agents, hooks, and/or MCP servers into one installable package. One folder per plugin.

```
plugins/
  my-plugin/
    .claude-plugin/plugin.json
    skills/
    commands/
    agents/
    hooks/
```

## Third-party

Plugins from other authors are listed with credit in [third-party.md](third-party.md).
